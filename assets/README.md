# Assets

| Folder | Contents |
|---|---|
| `icons/` | 67 PNGs stored in the `.tft` as pictures 0–66. File prefix = picture ID. `_sheet.png` is an overview (don't import it). |
| `fonts/charset.txt` | The characters the screen fonts contain (ASCII + `°`), for USART HMI's font tool. |
| `fonts/*.ttf` | Not committed; run `tools/fetch_fonts.sh` to download them. |
| `boot/boot.gif` | Boot animation (272×480, 106 frames, 5 s). |

## Icons

Generated by `tools/make_icons.py` from Material Design Icons (the set
Mainsail uses). Pictures on the panel are opaque, so every icon is rendered
onto the exact colour it sits on:

- IDs 0–63: 32 button icons, each as *normal* (even ID, on `#2a2a2a`) and
  *pressed* (odd ID, on `#1565c0`).
- IDs 64–66: small 24 px status icons (nozzle, bed, fan) on `#1e1e1e`.

New icons must be **appended** to the list in `make_icons.py`; inserting one
would shift every later ID and break the screen program.
